# Completion sound

Put the sound that should play when the puzzle is finished here as **`complete.mp3`**.

- To use another name or format (`.wav`, `.ogg`, `.m4a`), change `completionSound` in `js/config.js`.
- You can also choose a file from the running app: **Settings (gear icon) → Completion sound → Choose file…**.
  The browser remembers that file on this machine, and it takes priority over `complete.mp3`.
- If there is no file, a built-in chime plays instead, so the ending is never silent.
